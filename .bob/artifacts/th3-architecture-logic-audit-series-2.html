۳. معماری ماژول‌های TH3 — لایه‌بندی

لایه Data Model (بدون چارت):
TH3Types.mqh — struct‌ها: TH3Point، TH3Skeleton، TH3Pattern، TH3DrawingSession

لایه Math (pure — بدون chart objects):
TH3Math.mqh ← TH3Pivots.mqh (شامل Pivots_A + B)
توابع: SnapToOHLC، CalculateWaveAngle، TH3SkeletonFromBars، TH3LockedStep، TH3RealDAt

لایه State (session drawing):
TH3Controller.mqh — state machine: IDLE → PLACING → COMPLETE
یک instance: g_th3Session (جایگزین ۱۲ متغیر global قدیمی)

لایه Store (in-memory registry):
TH3PatternStore.mqh — g_th3Patterns (حداکثر ۶۴ pattern)

لایه Renderer (chart objects):
TH3Renderer.mqh (= Renderer_A + B + C) — model → chart objects

لایه Tool (entry dispatcher):
TH3Tool.mqh (= Tool_A + B + C + D + Recorder + DatasetPaths inline)

وابستگی‌های کلیدی:

  • TH3Math ← TH3Pivots ← TH3Types
  • TH3PatternStore ← TH3Math
  • TH3Controller ← TH3Types
  • TH3Renderer ← TH3PatternStore + TH3Controller
  • TH3Tool ← همه لایه‌های بالا
