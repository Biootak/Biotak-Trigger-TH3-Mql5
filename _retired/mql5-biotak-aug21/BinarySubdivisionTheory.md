## 1. مقدمه و انگیزه

### مشکل اصلی
سیستم فرکانس قبلی TH3 از آرایه ثابت ۷۶ عنصری استفاده می‌کرد:
- **۳۳ مقدار اصلی:** n/32 × 100% برای n=1..38 + 120.0
- **۴۳ میانگین هندسی (GM):** √(a×b) بین هر دو مقدار مجاور

**مشکلات:**
1. **۲۲ مقدار GM اشتباه:** میانگین هندسی √(a×b) همیشه < میانگین حسابی (a+b)/2 (نابرابری AM-GM). نقطه میانی صحیح بین دو مقدار خطی = AM نه GM.
2. **محدودیت مصنوعی:** آرایه در index 75 (120%) متوقف می‌شد — هیچ فیدبکی به کاربر.
3. **حافظه ثابت:** ۷۶×۸ = ۶۰۸ بایت آرایه ثابت بدون نیاز.
4. **inconsistency:** بین n/32 (خطی) و GM (غیرخطی) ترکیب هیبریدی نادرست.

### راه‌حل: تقسیم دودویی خالص
```
frequency(index) = index × (100 / 2^6) = index × 1.5625%
```
- بدون آرایه، بدون lookup — فقط یک ضرب ساده در runtime
- ۱۲۸ فرکانس (1.5625% تا 200%) بجای ۷۶ (3.125% تا 120%)
- هر مقدار دقیقاً n/64 × 100% — تقسیم دودویی خالص
- سازگار با نظریه فرکتالی (×4 = 2²)

## 2. قضیه بنیادی: بازنمایی دودویی

### کشف ۱: هر عدد حقیقی قابل نمایش به شکل n/2^k × 100%

> **قضیه:** مجموعه {n/2^k : n ∈ ℤ, k ∈ ℕ} (اعداد دوگانی/dyadic rationals) در ℝ چگال است.
> یعنی برای هر عدد حقیقی x و هر ε > 0، یک n/2^k وجود دارد که |x - n/2^k| < ε.

**اثبات:** برای دقت ε، کافیست k را به اندازه‌ای بزرگ انتخاب کنیم که 1/2^k < ε. سپس n = ⌊x × 2^k⌉.

**مفهوم عملی:** با افزایش depth (k)، هر قیمت هدف را می‌توان با دقت دلخواه نمایش داد.

| Depth k | Step (100/2^k) | Grid Points (0-100%) | Precision |
|---------|----------------|----------------------|-----------|
| 1 | 50% | 2 | بسیار درشت |
| 2 | 25% | 4 | درشت |
| 3 | 12.5% | 8 | متوسط |
| 4 | 6.25% | 16 | مناسب |
| 5 | 3.125% | 32 | خوب (= n/32 قدیمی) |
| **6** | **1.5625%** | **64** | **عالی** ← انتخاب ما |
| 7 | 0.78125% | 128 | بسیار ریز |

## 4. ارتباط فرکتالی — ۹ تایم‌فریم

## 5. مسیر دودویی — درخت باینری

### کشف ۵: هر فرکانس = مسیر L/R در درخت باینری

هر index ∈ [1, 64] معادل یک مسیر ۶-بیتی در درخت باینری 0-100% است:

```
                    50% (root)
                   /          \
              25%                75%
            /     \            /     \
         12.5%   37.5%     62.5%   87.5%
        / \     / \       / \     / \
      6.25 18.75 31.25 43.75 56.25 68.75 81.25 93.75
      ...
```

مثال: فرکانس 28.125% (index 18):
```
50% → L → 25% → R → 37.5%... → 28.125%
Binary: 010010 (18 in binary)
Path:   L-R-L-L-R-L
```

### کشف ۶: عملیات XOR = جابجایی متقارن

اگر index₁ XOR index₂ = 2^k، آنگاه فرکانس‌ها قرینه حول سطح 2^k هستند.
- مثال: 18 XOR 14 = 28 → فرکانس‌های 28.125% و 21.875% قرینه حول 25% هستند
- `28.125 + 21.875 = 50.0 = 2 × 25.0` ✓

## 7. سلسله‌مراتب 2-adic

### کشف ۹: ارزش‌گذاری 2-adic = اهمیت ذاتی فرکانس

**تعریف:** v₂(n) = بزرگترین توان ۲ که n بر آن بخش‌پذیر است.

```
v₂(n) │ Indices (1-64)        │ Frequency Resolution │ Count
──────┼───────────────────────┼──────────────────────┼──────
  6   │ 64                    │ 100% (whole)         │   1
  5   │ 32                    │ 50% (half)           │   1
  4   │ 16, 48                │ 25% (quarter)        │   2
  3   │ 8, 24, 40, 56        │ 12.5% (eighth)       │   4
  2   │ 4,12,20,28,36,44,52,60 │ 6.25% (16th)       │   8
  1   │ 2,6,10,...,62         │ 3.125% (32nd)        │  16
  0   │ 1,3,5,...,63          │ 1.5625% (64th)       │  32
```

**الگو:** count(depth=d) = 2^(5-d) — هر سطح بالاتر نصف تعداد.
- depth بالاتر = فرکانس بنیادی‌تر = "بلندتر" (louder)
- depth پایین‌تر = فرکانس ظریف‌تر = "آرام‌تر" (softer)

### کشف ۱۰: رابطه depth و scoring

در `ScoreHarmonicPhase` (فقط بخش depth، وزن ۱۵% از کل):
```
depth ≥ 6: score = 0.40 (octave — whole numbers of 100%)
depth = 5: score = 0.36 (halves)
depth = 4: score = 0.32 (quarters)
depth = 3: score = 0.28 (eighths)
depth = 2: score = 0.24 (16ths)
depth = 1: score = 0.20 (32nds = old primaries)
depth = 0: score = 0.12 (64ths = finest grid)
```

هرچه فرکانس بنیادی‌تر (depth بالاتر)، امتیاز هارمونیک بیشتر.
علاوه بر depth، سه عامل دیگر نیز در امتیاز هارمونیک نقش دارند:
- نزدیکی به توان ۲ (max 0.15)
- رابطه با نسبت AB/XA (max 0.25)
- پل فرکتالی: تطابق با MODIFIED_FRACTAL_PERCENTAGES × 2^n (max 0.20)

## 9. خواص جبری — گروه Z/64Z

### کشف ۱۳: ساختار گروهی

مجموعه {0, 1, 2, ..., 63} با عمل جمع mod 64 یک گروه دوری تشکیل می‌دهد: ℤ/64ℤ

**خواص:**
- **جمع mod 64:** (i + j) mod 64 = فرکانس ترکیبی
- **قرینه:** -i mod 64 = 64-i → فرکانس مکمل (i% + (64-i)% = 100%)
- **مرتبه عناصر:** ord(i) = 64/gcd(i,64)
  - ord(1)=64 — مولد (همه فرکانس‌ها قابل دسترسی)
  - ord(32)=2 — نقطه تقارن (50% → 100% → 50%)

### کشف ۱۴: عملیات AND و OR

```
i AND j = max common binary structure
i OR j  = min containing binary structure
i XOR j = symmetric difference
```

مثال عملی:
- 28.125% (index 18) AND 25% (index 16) = index 16 = 25%
  → بزرگترین ساختار مشترک = Quarter 1
- 28.125% (index 18) XOR 50% (index 32) = index 50 = 78.125%
  → تفاوت متقارن

## 10. نظریه اطلاعات — ۶ بیت دقت

### کشف ۱۵: log₂(64) = 6 بیت

هر فرکانس در محدوده 0-100% با ۶ بیت قابل نمایش است:

```
Bits: b₅ b₄ b₃ b₂ b₁ b₀
      32 16  8  4  2  1  (weights)

28.125% = index 18 = 010010₂
  b₅=0 (< 50%)
  b₄=1 (≥ 25%)  
  b₃=0 (< 37.5%)
  b₂=0 (< 31.25%)
  b₁=1 (≥ 28.125%)
  b₀=0 (exact at 28.125%)
```

**تفسیر:** هر بیت یک سوال باینری "بالا یا پایین؟" پاسخ می‌دهد:
- بیت ۵: بالای 50% یا پایین؟
- بیت ۴: بالای 25%/75% یا پایین؟
- ...
- بیت ۰: آخرین تنظیم ریز

### آنتروپی و بهینگی
6 بیت = 64 حالت = H = log₂(64) = 6 شانون
- depth 5 (32 حالت) = 5 بیت — ناکافی (resolution قدیمی)
- depth 7 (128 حالت) = 7 بیت — بیش از حد (precision اضافی)
- depth 6 = **بهینه** از نظر trade-off دقت/پیچیدگی

## 12. کاربرد عملی — نظریه ۳+۲ گام

### نظریه حرکت بازار

> **سه گام حرکت → حداقل یک گام برگشت**

```
       Step1        Step3        Step5        Step7
  C ────┬────────────┬────────────┬────────────┬───
        │  1×base    │  3×base    │  5×base    │
        │            │            │            │
        │ حرکت ۱     │ حرکت ۲     │ حرکت ۳     │ Stop-Hunt 2
        │            │ برگشت ۱    │ Stop-Hunt 1│
```

### پنج گام = سه واحد خالص + دو استاپ‌هانت

| Step | Multiplier | Nature | Description |
|------|-----------|--------|-------------|
| Step1 | 1× | حرکت خالص | اولین هدف — ورود محافظه‌کارانه |
| Step3 | 3× | حرکت خالص | هدف اصلی — 50% reversal zone |
| Step5 | 5× | حرکت خالص + Stop-Hunt | شکار استاپ‌لاس Step3 |
| Step7 | 7× | Stop-Hunt | شکار استاپ‌لاس Step5 |

### چرا فقط اعداد فرد؟
- Step_n = C ± n×baseUnit برای n = 1, 3, 5, 7
- اعداد زوج (2, 4, 6) = "فضای بین" — ناحیه بلاتکلیفی
- حرکات بازار ترجیح دارند در سطوح فرد (n/2 + remainder) متوقف شوند
- این با ساختار درخت باینری هماهنگ است: اعداد فرد = برگ‌ها (leaves)

### نقش فرکانس در pattern

```

frequency = 25% (index 16, depth=4, Quarter):
  baseUnit = AB × 0.25
  Step3 = C ± 0.75 × AB ← هدف در 75% فاصله AB

  baseUnit = AB × 0.50

frequency = 28.125% (index 18, depth=1, DEFAULT):
  baseUnit = AB × 0.28125
  Step3 = C ± 0.84375 × AB ← هدف نزدیک 84% فاصله AB
```

## پیوست الف: پیاده‌سازی کد

### توابع کلیدی در ProjectConstants.mqh

```mql5
// Binary Subdivision Constants
const int    BINARY_SUBDIVISION_DEPTH = 6;
const double BINARY_SUBDIVISION_STEP  = 1.5625;  // 100.0 / 64
const int    MIN_TH3_FREQ_INDEX       = 1;       // 1.5625%
const int    MAX_TH3_FREQ_INDEX       = 128;     // 200.0%
const int    DEFAULT_TH3_FREQ_INDEX   = 18;      // 28.125%

// Runtime frequency calculation — no static array needed
double GetFrequencyByIndex(int index) {
    return index * BINARY_SUBDIVISION_STEP;
}

// Migration: find nearest valid index for any frequency value
int FindNearestFreqIndex(double freqPercent) {
    if(freqPercent <= 0) return MIN_TH3_FREQ_INDEX;
    int idx = (int)MathRound(freqPercent / BINARY_SUBDIVISION_STEP);
    if(idx < MIN_TH3_FREQ_INDEX) idx = MIN_TH3_FREQ_INDEX;
    if(idx > MAX_TH3_FREQ_INDEX) idx = MAX_TH3_FREQ_INDEX;
    return idx;
}

// 2-adic valuation: depth of binary subdivision
int GetBinaryDepthLevel(int index) {
    if(index <= 0) return 0;
    int depth = 0;
    while((index & 1) == 0) { depth++; index >>= 1; }
    return depth;
}
```

## 13. سیستم امتیازدهی هوشمند ۴ مولفه‌ای

### معماری کلی

سیستم امتیازدهی فرکانس از ۴ مولفه مستقل تشکیل شده که هر کدام یک جنبه 
متفاوت از "خوب بودن" فرکانس را ارزیابی می‌کنند:

```
Total = 0.50 × Midpoint + 0.25 × Time + 0.15 × Harmonic + 0.10 × History
```

### ۱. امتیاز نقطه میانی (50%)
- Step3 = C ± 3×baseUnit در هر فرکانس محاسبه می‌شود
- فاصله Step3 تا نزدیک‌ترین سطح بازگشت (از ۴۲ مرجع) اندازه‌گیری می‌شود
- score = 1/(1 + 10×error/AB) — افت سریع با فاصله
- ۷ سطح بازگشت هر موج (بجای ۴ قبلی):
  - **50% حسابی و Gann:** bonus +25% (تریگر اصلی TH3)
  - **38.2% و 61.8%:** bonus +20% (خانواده φ گیلمور — نسبت طلایی)
  - **78.6%:** bonus +15% (√φ — بازگشت عمیق)
  - **25% و 75%:** بدون bonus (ثانویه)
- مرجع: Geometry of Markets Vol II, صفحه ۱۱ — سه خانواده نسبتی

### ۲. امتیاز زمانی Gann (25%)
سه زیرمولفه:
- **70%:** رابطه هارمونیک CD/AB و CD/BC (نزدیکی به ۰.۵، ۱.۰، ۱.۵، ...)
- **20%:** ثبات زاویه Gann (نسبت قیمت/زمان CD مشابه AB)
- **10%:** رزونانس فرکانس-زمان (freq/100 هارمونیک BC/AB)

### ۳. امتیاز هارمونیک + پل فرکتالی (15%)
پنج زیرمولفه:
- **max 0.40:** عمق دودویی (depth 0→0.12 تا depth 6→0.40)
- **max 0.15:** تشخیص نسبت خاص:
  - الف) توان ۲ (اکتاو خالص): +0.15
  - ب) پنجم کامل (3×2^n): +0.08
  - ج) **نسبت مقدس گیلمور (φ):** +0.12 برای primary (38.2%, 61.8%, 78.6%, 161.8%)
  - د) نسبت مقدس ثانویه: +0.07 (23.6%, 70.7%, 127.2%, 141.4%, 173.2%, ...)
- **max 0.25:** رابطه فرکانس با نسبت AB/XA
- **max 0.20:** پل فرکتالی — تطابق با MODIFIED_FRACTAL_PERCENTAGES×100 × 2^n

**نسبت‌های مقدس گیلمور (۱۸ عدد از کتاب Geometry of Markets):**
```
14.6%, 18.6%, 23.6%, 30.0%, 38.2%*, 44.7%, 48.6%, 52.6%, 57.7%,
61.8%*, 70.7%, 78.6%*, 87.5%, 127.2%, 141.4%, 161.8%*, 173.2%, 190.2%
```
*ستاره = primary (bonus بالاتر)*

### ۴. امتیاز تاریخچه (10%)
- حلقه ۸ عنصری (ring buffer) آخرین نتایج
- دو زیرمولفه:
  - **60%:** رابطه اکتاو — آیا فرکانس فعلی مضرب ۲^n فرکانس قبلی است؟
  - **40%:** شباهت مقیاس — آیا فاصله AB مشابه الگوهای قبلی است؟
- وقتی تاریخچه خالی: score = 0.5 (خنثی)

### سه خانواده نسبتی گیلمور

| خانواده | ریشه | نسبت‌های اصلی | پوشش در TH3 |
|---------|------|-------------|-------------|
| **HARMONIC** | √2 | 0.125, 0.250, 0.500, 1.000, 2.000, 4.000 | ✅ binary subdivision |

### ویژگی‌های جدید v4.0
- **سطوح بازگشت φ:** 38.2%, 61.8%, 78.6% به عنوان midpoint هر موج اضافه شد
- **تشخیص نسبت مقدس:** فرکانس‌های نزدیک به نسبت‌های گیلمور bonus هارمونیک می‌گیرند
- **تلرانس "lost motion":** ±1.5625% (یک ایندکس) مطابق ۱-۲% گیلمور
- **۴۲ مرجع midpoint:** ۶ موج × ۷ سطح (بجای ۶×۴=۲۴ قبلی)

### ویژگی‌های قبلی
- **فیلتر حداقل گام:** فرکانس‌هایی که Step1 < 2 پیپ تولید می‌کنند رد می‌شوند
- **Tie-break دودویی:** در امتیاز مساوی، فرکانس با depth بالاتر انتخاب می‌شود
- **لاگ Top-3:** سه بهترین کاندیدا با تمام مولفه‌ها در Experts لاگ می‌شوند
- **بهینه‌سازی مجدد:** کشیدن نقاط A/B/C فرکانس را مجدداً بهینه می‌کند
